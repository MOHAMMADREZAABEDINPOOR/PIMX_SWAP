# بستهٔ انتشار PIMXSWAP

فایل `PIMXSWAP-Setup.exe` نصب‌کننده و `PIMXSWAP.exe` نسخهٔ قابل اجرا بدون نصب است. راهنمای استفاده، توضیح حریم خصوصی و متن مجوز وابستگی‌ها کنار این فایل‌ها و داخل بستهٔ نصب قرار دارند. `SHA256.txt` برای بررسی یکسان‌بودن فایل‌هاست.

پس از انتخاب زبان و چیدمان‌ها، متن اشتباه را در برنامهٔ مقصد انتخاب کنید و `Ctrl+Shift+Space` بزنید. بدون انتخاب، متن خط جاری پیش از مکان‌نما تبدیل می‌شود؛ برای چند خط، همهٔ متن موردنظر را انتخاب کنید. جملهٔ ناقص هم تبدیل می‌شود. نتیجه‌های مبهم را بازبینی کنید.

تست واقعی Word، پاورپوینت و Chrome روی این سیستم انجام شده است. گزارش جزئیات و محدودیت‌ها در `release-checklist.md` و `docs/validation.md` قرار دارد. کارکرد در همهٔ برنامه‌ها یا نبود هرگونه باگ تضمین نمی‌شود؛ جست‌وجوی Start ویندوز هنوز تست عملی موفق ندارد.

برای انتشار عمومی، امضای معتبر ناشر، تعیین مجوز خود برنامه و انتخاب محل انتشار باقی است. گواهی امضای معتبر در سیستم پیدا نشد؛ اسکریپت `scripts/sign-release.ps1` برای زمانی که گواهی تهیه شود آماده است. بعد از امضا باید هش‌ها مجدداً تولید شوند. تست نصب روی یک ویندوز تمیز و نسخه‌های دیگرِ مورد پشتیبانی نیز لازم است. هیچ فایلی در اینترنت منتشر نشده است.
